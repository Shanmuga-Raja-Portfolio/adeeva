Maker Studio

Seven offline, family-safe games about running a small creative business — bake, cook, make, mend, and grow a tiny studio of your own. Free and open source.

Play online (Cloudflare Pages) Get the code on GitHub Download v1.0.0 (.zip)

This page describes the project. The game itself runs on Cloudflare Pages, or on your own computer from the source code.

The games

Game The trade
Adeeva Craft workshop: take requests, choose materials, make the piece well
Six Kitchens Restaurant kitchen: prep, cook, plate and serve under the clock
Patisserie Atelier Bakery: bakes, cakes and a shop of your own
Jewellery Bench Fine jewellery: bench work, collections, lantern nights
Interior Studio Home makeovers: plan, decorate and show the finished room
Thrift-Flip Studio Second-hand finds: mend, style and resell
Workshop & Wood Woodworking: commissions from the neighbourhood

Built for families

  • Offline first. It installs as an app (PWA) and plays with the network off.
  • No accounts, no ads, no purchases, no analytics. Nothing is collected.
  • Gentle pacing: no streaks, and nothing punishes a child for walking away.
  • A parent page inside the app explains what is stored on the device and how to forget it.

Run it on your own computer

You need Node.js 24 and pnpm 11 (corepack enable gives you pnpm). 

git clone https://github.com/Shanmuga-Raja-Portfolio/adeeva.git
cd adeeva
pnpm install
pnpm dev        # play at the local URL it prints

pnpm build makes the offline app in dist/; pnpm preview serves it locally. On Windows, double-click Play Maker Studio.cmd.

Host your own copy

Build with pnpm build and serve dist/ from the site root on any static host. Cloudflare Pages is the tested setup: it applies the security headers in public/_headers. The repository's release workflow shows the exact deploy.
